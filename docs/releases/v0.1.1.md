# CiteGeist v0.1.1

This compatibility release aligns CiteGeist with the Epistemap confidence
overhaul while preserving public bibliography and verification interfaces.

## Included

- canonical `match_score` identity-resolution naming with legacy
  `confidence` aliases and warnings;
- reviewed identity outcomes and calibration rows for bibliographic matching;
- dry-run-first confidence migration support for provenance tables;
- deterministic Epistemap-compatible graph export;
- explicit separation of identity resolution, topic relevance, retrieval rank,
  and claim support semantics.

## Compatibility

Serialized legacy aliases remain readable for the compatibility window. The
Epistemap-compatible graph profile remains a deterministic JSON projection and
does not add a runtime Epistemap dependency.

## Validation

- `.venv/bin/python -m pytest -q`: 295 passed, 5 skipped, 13 expected
  deprecation warnings.
